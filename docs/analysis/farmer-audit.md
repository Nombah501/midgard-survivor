# Midgard Survivors: farmer audit against 0.2.3

**What this does.** The farmer is an in-process controller for desktop single-player runs (optionally with local AI teammates), not a UI macro or a town bot. This audit assumes one unattended session must survive repeated runs and must not endanger the player's primary profile. **Verdict: rewrite the run controller and persistence boundary; keep the game's AI, the minimal versioned hook, and selected policy ideas. Do not treat the installed setup as production-safe.** The pack is current; that does not make the orchestration current or safe.

Evidence notation: `F/` = `/home/n501/games/midgard-survivors/farmer/`; `G/` = `analysis/src/` (effective base 0.1.259 + bridge 0.2.0 + official 0.2.3); `U/` = `~/.local/share/godot/app_userdata/Midgard Survivors/`; the short session labels in the history table expand to `F/logs/run-20261117-<label>.log`. Code findings are from static inspection; reported history is observed, not a live 0.2.3 reproduction. No game or farmer files were changed and no game session was started.

## 4. Findings and minimum fix direction

| Finding | Severity | Evidence file:line | Fix direction |
|---|---|---|---|
| **(a) Real: end detected before game settlement, and HP ≠ result.** Death sets `running=false` before the delayed `_end_run(endless)`; farmer may account and keep before banking or before an offer exists. A short restart can let the old death timer finalize the *replacement* player. Boss pointer is cleared on normal MVP kill and can also name an elite; active hero HP does not distinguish a forced/debug defeat. | Critical | `F/farmer.gd:289–292,322–445`; `G/main.gd:5288–5298,11509–11520,15644–15680,15726–15749` | Use one authoritative finalized event with result/reason and run identity; consume it after settlement and before restart. |
| **(b) Real, but `false` is not a rollback.** Timeout `_end_run(false)` does settle partial rewards: gathered ore, bag/card sale, eligible daily bonus, class XP (danger/featured-adjusted), record and achievements; pickups already credited remain. It does not itself mark the map cleared, nor does it settle discarded worn loot. Stop-file/max-time use `abandon_run`, which banks stats/XP but does not run that inventory/end-screen path. `forced=true` masks the HP heuristic only on farmer timeout. | High | `F/farmer.gd:317–327,1193–1203`; `G/main.gd:356–393,11547–11567,15699–15749,16009–16033,16068–16086`; `G/menus.gd:21748–21777` | Define the intended result and transaction for timeout, abort and finish-current-run; log each separately. |

## 5. Gaps for a full farmer

- **Town economy:** no budgeted Kafra/Sage upgrade buyer, storage refiner, Star Smith rolling/locking/Tear use, album/pet/loadout choice, or reserve-aware fuse. The game has real mechanisms (upgrades `G/menus.gd:19094–19112`, permanent refine with fee/ore and downgrade/break `25414–25475`, Potential roll `G/star_smith_panel.gd:742–757`, `G/potential.gd:115–155`, card/pet/loadout `G/save.gd:692–699,1378–1380,2162–2173`). The farmer harvests loot, triggers game in-run automation and reads current saved gear/pets; that is not town orchestration. It *does* support standard Rebirth and Rebirth Level when enabled (`F/farmer.gd:408–412,900–905`), contrary to `F/README.md:190–192`.
- **Tower, Hel Tower, Festival:** current code reads tower/Hel status only (`F/farmer.gd:639–645`) and always launches normal `start_run`. `World.start_tower(index,floor,hel)` consumes/uses a tower build; Festival uses a dedicated copy of a build and training mode; ordinary run start clears active tower/festival nodes (`G/main.gd:1268–1280,1563–1583,1640–1674`). Native end-screen build capture is gated off under autopilot (`G/menus.gd:13578–13586`). A dark Karma run or normal Endless is neither tower nor festival.
- **Inventory lifecycle:** no safe capacity target, locked/loadout/eternal protection policy for swaps, sell/salvage pass, overflow alert, or gear re-equip. `Save.remove_from_storage` can remove loadout references; the native swap warns about both loads and eternals (`G/save.gd:2104–2115`; `G/menus.gd:21617–21619,21655–21660`). Current conservative refusal to swap is safer than automatic eviction, but permanently stops selecting drops on a full profile.
- **Safe stop/resume and crash recovery:** no finish-current versus abort command, no checkpoint of farmer scheduler/cursors/goals/totals, no way to resume a farmer-driven run through stock `RunSave.save`, no automatic validation/use of backups, no retry/backoff supervisor, no typed terminal outcome. Pause and no-world periods cannot be proven healthy from stale status. Monitor unique session/process identity, last state transition, actual raid/Morroc mode and independent clocks, committed XP/currency/loot, errors, stall times, and log retention. Long-session evidence shows hitches/teardown warnings but does not prove ongoing memory growth or a particular crash cause.
