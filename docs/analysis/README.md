## Ключевые выводы

- Награды за убийства начисляются сразу; `_end_run` банкует ore, продажу сумки,
  классовый XP, daily, keep и рекорд.
- `danger_reward` линеен, HP мобов растёт экспоненциально; оптимум danger —
  не максимум, а точка максимального потока убийств/ресурсов. Стадия важнее
  danger: плотные поздние карты дают на порядок больше.
- Star Crumb с обычных убийств — только hell≥10 (danger 25+); иначе MVP (3.5%).
- Победа не хранится как флаг забега: `run_mvps` (дельта) — надёжный признак;
  `raid.state` остаётся `"won"` после выхода, `menus._mode=="victory"` — UI.
- `menus.auto_pick` использует `Bot.pick_choice` (игнорирует `pick_order`);
  фермер должен вести draft сам.
- `run.sh` не должен передавать пользовательские аргументы `--...`: Updater
  отключает все патчи. Для endless используется `GameData.karma_test`.
- `Save.add_to_storage` теряет `pot`; запись склада нужно делать одной
  транзакцией с сохранением potential.
- Старый фермер: реальные проблемы с детектом конца, draft, таймингом,
  keep-свопом, job-гонкой и изоляцией профиля; рекомендация — переписать
  контроллер, оставив штатную игру и минимальный hook.
